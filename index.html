قائمة مهام تجهيز ونشر أونلاين (المطلوب منك بالترتيب)

اضغط على المربع مقابل كل خطوة عند الانتهاء منها لتحديث مؤشر جاهزية التطبيق للعمل مع فريقك:

خيار 1: النشر المجاني الدائم عبر GitHub Pages

طريقة رسمية مجانية تضمن بقاء تطبيقك أونلاين برابط خاص مدى الحياة بدون أي مصاريف.

1

إنشاء مستودع (Repository)

سجل دخول في GitHub.com ثم اضغط على New Repository. سمّه باسم مثل tickets-app واجعله Public.

2

رفع الملف (uploading index.html)

احفظ كود التطبيق في ملف باسم index.html على جهازك. داخل صفحة المستودع في جيتهاف اضغط uploading an existing file وارفع هذا الملف تماماً ثم اضغط Commit changes.

3

تفعيل Pages واقتناص الرابط

ادخل على Settings > Pages. في خيار Branch اختر main ثم اضغط Save. خلال دقيقة سيظهر لك رابط الويب العام الشغال أونلاين!

خيار 2: النشر السريع للغاية في 30 ثانية (Netlify Drag & Drop)

أسهل طريقة بدون الحاجة لإنشاء مستودعات كود. السحب والإفلات المباشر للملف.

خطوات Netlify Drop:

  1. ضع ملف index.html داخل مجلد على جهازك.
  2. افتح موقع Netlify Drop (app.netlify.com/drop).
  3. اسحب المجلد وأسقطه داخل المربع المخصص على الشاشة.
  4. مبروك! سيمنحك الموقع فوراً رابط أونلاين عام مجاني يتيح لجميع زملائك فتح التطبيق والعمل عليه.

بديل Vercel:

يمكنك أيضاً التسجيل في موقع Vercel.com واستيراد الملف أو مشروعك بضغطة زر واحدة للحصول على سرعة فائقة واستضافة مجانية مدى الحياة.

إعداد Google Apps Script المباشر للتفاعل أونلاين

هذا الكود يجعل Google Sheet يقرأ ويكتب البيانات مع الأبلكيشن لجميع اليوزرز أونلاين في نفس الوقت.

خطوات التثبيت في Google Sheets:

  1. افتح ملف Google Sheet الخاص بك من حسابك.
  2. من القائمة العلوية اختر Extensions (الإضافات) > Apps Script.
  3. احذف أي كود مكتوب والصق الكود الموجود في النافذة المجاورة.
  4. اضغط على Deploy (نشر) > New Deployment (نشر جديد).
  5. في نوع التثبيت اختر Web App.
  6. مهم جداً: اجعل خيار Execute as: Me وخيار Who has access: Anyone.
  7. اضغط Deploy وانسخ الرابط الناتج وضعه في خانة Webhook URL بالأبلكيشن.

function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheets()[0];
  var data = sheet.getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var matchId = data.matchId;
    var tabName = data.tabName;
    var resolution = data.resolutionNotes;
    var solvedBy = data.solvedBy;

    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName(tabName) || ss.getSheets()[0];
    var values = sheet.getDataRange().getValues();

    // البحث والتحديث المباشر برقم Match ID
    for (var i = 1; i < values.length; i++) {
      if (values[i][0].toString() === matchId.toString()) {
        sheet.getRange(i + 1, 7).setValue(resolution); // العمود 7: الحل
        sheet.getRange(i + 1, 8).setValue(solvedBy);    // العمود 8: اليوزر
        sheet.getRange(i + 1, 9).setValue("Solved");   // العمود 9: الحالة
        return ContentService.createTextOutput(JSON.stringify({status: "success"}))
               .setMimeType(ContentService.MimeType.JSON);
      }
    }
    return ContentService.createTextOutput(JSON.stringify({status: "not_found"}));
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({error: err.toString()}));
  }
}
